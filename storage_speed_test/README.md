# Storage Speed Test Benchmark

Comprehensive storage performance benchmarking tool for testing read/write speeds across multiple mount points.

## Overview

This benchmark suite tests file transfer performance between different storage systems (HDD, SSD, network shares) using various file sizes and patterns.

## Components

- **`storage_speed_test.sh`** - Main bash script that runs the benchmark tests
- **`plot_storage_results.R`** - R script to visualize results using ggplot2
- **`pictures/`** - Directory containing generated plots

## Requirements

### For running tests:
- `bash`
- `bc` (calculator for floating-point arithmetic)
- `dd` (data duplicator for file generation)
- Write access to mount points

### For plotting:
- R (≥ 4.0)
- R packages: `ggplot2`, `dplyr`, `tidyr`, `viridis`, `scales`

## Installation

Install required R packages:

```r
install.packages(c("ggplot2", "dplyr", "tidyr", "viridis", "scales"))
```

## Usage

### 1. Configure Mount Points

Edit `storage_speed_test.sh` and modify the `MOUNTS` array to include your storage locations:

```bash
MOUNTS=(
    "/mnt/hdd_storage"
    "/mnt/ssd_storage"
    "/mnt/syn_hdd"
    "/mnt/syn_ssd"
)
```

### 2. Run Benchmark

```bash
chmod +x storage_speed_test.sh
./storage_speed_test.sh
```

The script will:
- Check mount point accessibility
- Generate test files (1MB, 100MB, 1GB, and 100 small files)
- Test all source → destination combinations
- Generate results in both text and CSV format
- Clean up temporary files

### 3. Generate Plots

After the benchmark completes, create visualizations:

```bash
Rscript plot_storage_results.R speed_test_results_YYYYMMDD_HHMMSS.csv
```

Replace the filename with the actual CSV file generated by the test.

## Test Types

The benchmark performs 4 different test types:

1. **Small File (1MB)** - Tests small file transfer performance
2. **Large File (100MB)** - Tests medium-large file transfers
3. **Huge File (1GB)** - Tests bulk data transfer capabilities
4. **Many Small Files (100 × 10KB)** - Tests metadata-intensive operations

## Output Files

### Text Report
`speed_test_results_YYYYMMDD_HHMMSS.txt` - Human-readable summary with:
- Test configuration
- Results table
- Performance analysis (fastest/slowest operations)

### CSV Data
`speed_test_results_YYYYMMDD_HHMMSS.csv` - Machine-readable data with columns:
- Source
- Destination
- TestType
- Time_s
- Rate_MBps
- Size_bytes

### Plots (in `pictures/`)
1. **`storage_heatmap.png`** - Heatmap of transfer rates between all storage pairs
2. **`storage_testtype_comparison.png`** - Average rates by test type with error bars
3. **`storage_pairs_comparison.png`** - Ranked comparison of storage pairs
4. **`storage_distribution.png`** - Box plots showing rate distributions
5. **`storage_trends.png`** - Line plots showing performance trends across test types

## Interpreting Results

### Transfer Rate (MB/s)
Higher values indicate better performance. Typical ranges:
- **Local SSD → SSD**: 200-500 MB/s
- **Local HDD → HDD**: 80-150 MB/s
- **Network shares**: 10-120 MB/s (depends on network speed)

### Key Patterns to Look For
- **Same-storage transfers** (e.g., SSD → SSD on same disk) may show cache effects
- **Many small files** typically show lower MB/s due to metadata overhead
- **Network transfers** may vary significantly based on network congestion

## Customization

### Modify Test Sizes

Edit these variables in `storage_speed_test.sh`:

```bash
SMALL_FILE_SIZE="1M"      # Change to desired size
LARGE_FILE_SIZE="100M"    
HUGE_FILE_SIZE="1G"       
NUM_SMALL_FILES=100       # Number of small files to test
```

### Add More Mount Points

Simply add entries to the `MOUNTS` array:

```bash
MOUNTS=(
    "/mnt/hdd_storage"
    "/mnt/ssd_storage"
    "/path/to/new/storage"
)
```

## Troubleshooting

### Script fails with "No accessible mount points found"
- Verify mount points exist: `ls -ld /mnt/hdd_storage`
- Check write permissions: `touch /mnt/hdd_storage/test.txt`

### "bc calculator is required" error
Install bc:
```bash
# macOS
brew install bc

# Ubuntu/Debian
sudo apt-get install bc
```

### R plotting fails with missing packages
Install packages in R:
```r
install.packages(c("ggplot2", "dplyr", "tidyr", "viridis", "scales"))
```

## Notes

- The script uses **the same test data** for all transfers from each source mount to ensure fair comparison
- Destination files are deleted after each test to prevent disk space issues
- Temporary files are cleaned up automatically via EXIT trap
- First run from a mount point may be slower due to OS caching
